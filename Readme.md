# Предсказание конечной температуры сплава для металлургического комбината «Стальная птица»

## 📌 Описание проекта

Металлургический комбинат **«Стальная птица»** решил уменьшить потребление электроэнергии на этапе обработки стали. Для этого комбинату необходимо контролировать температуру сплава.

**Проблема:** нагрев стали до нужной температуры требует больших затрат электроэнергии. Без точного контроля конечной температуры сплава невозможно оптимизировать производственные расходы.

**Решение:** построена модель машинного обучения, предсказывающая конечную температуру сплава на основе данных о технологическом процессе. Модель позволит заказчику имитировать технологический процесс и уменьшить энергозатраты.

---

## 🎯 Цель исследования

Построить модель машинного обучения, которая предсказывает **конечную температуру сплава** на основе предоставленных заказчиком данных. Целевая метрика — **MAE < 6.8**.

---

## 🏭 Описание технологического процесса

Сталь обрабатывают в металлическом ковше вместимостью ~100 тонн, облицованном огнеупорным кирпичом. Расплавленную сталь заливают в ковш и подогревают графитовыми электродами до нужной температуры. Затем:

1. Из сплава выводится сера (**десульфурация**).
2. Добавлением примесей корректируется химический состав.
3. Отбираются пробы.
4. Сталь **легируют** — подают куски сплава из бункера или проволоку через трайб-аппарат.

Перед первой подачей легирующих добавок измеряют температуру и проводят химический анализ. Затем температуру повышают, добавляют легирующие материалы, продувают инертным газом, перемешивают и снова измеряют. Цикл повторяется до достижения целевой температуры и состава.

## 📂 Данные

Данные получены из нескольких источников:

| Файл | Описание |

| `data_wire_new.csv` | данные о проволочных материалах (объём, Wire 1…9) |
| `data_wire_time_new.csv` | данные о проволочных материалах (время) |

**Ключ объединения:** `key` — номер партии. В файлах может быть несколько строк с одинаковым `key` — они соответствуют разным итерациям обработки.

## 🔬 Ход исследования

### Шаг 1. Чтение датафреймов и первичный осмотр
- Загружены все 7 датафреймов.
- Приведены к каноничному виду названия столбцов.
- Даты преобразованы в формат `datetime`.
- Проведён первичный анализ: типы данных, пропуски, дубликаты.

### Шаг 2. Исследовательский анализ данных
- **`data_arc_new`:** обнаружены аномальные отрицательные значения `reactive_power` → удалены.
- **`data_bulk_new`:** большое число `NaN` (материал не использовался в сплаве).
- **`data_temp_new`:** обнаружены аномально низкие значения температуры (< 1500 °C) → удалены.
- **Дубликаты:** отсутствуют.
- **Выводы:** данные в основном гауссовидные с длинными хвостами, без ярких выбросов (кроме указанных).

### Шаг 3. Корреляционный анализ
- **`active_power` и `reactive_power`** коррелируют почти на 100% → оставлен только `active_power`.
- Некоторые материалы коррелируют друг с другом (пары 1–13, 4–9, 7–14) — используются вместе.
- Некоторые признаки имеют < 20 ненулевых значений (`bulk_8`, `wire_5`) → удалены.
- **VIF-анализ:** подтверждена мультиколлинеарность между мощностями.

### Шаг 4. Объединение датафреймов
- Объединены данные по материалам, проволочкам, газу, температуре и энергии.
- Созданы новые признаки:
  - **`energy`** — затраченная энергия на сплав (`active_power × time_delta`);
  - **`mean_temperature`** — средняя промежуточная температура (все измерения, кроме последнего).
- Все времена пересчитаны относительно начала первого нагрева (в секундах).
- Удалены признаки с < 20 событиями.
- `NaN` в материалах/проволочках заполнены нулями (материал не подавался).
- `key` сделан индексом.

### Шаг 5. Исследовательский анализ объединённого датафрейма
- Распределения `energy`, `temperature`, `mean_temperature`, `gas` — гауссовидные с длинными хвостами.
- Времена подачи материалов/проволочек имеют редкие значения > 6 часов, но их мало.
- Пустых строк и дубликатов нет.

### Шаг 6. Корреляционный анализ объединённого датафрейма
- Обнаружена сильная корреляция между временами подачи и объёмами материалов/проволочек → времена удалены.
- VIF-анализ подтвердил отсутствие мультиколлинеарности после удаления.
- Утечки целевого признака нет.

### Шаг 7. Разработка модели машинного обучения
- **Разделение:** train/test = 3:1 (`RANDOM_STATE=100225`, `TEST_SIZE=0.25`).
- **Пайплайн:** `MinMaxScaler` + модель.
- **Рассмотренные модели:**
  - `LinearRegression`
  - `Lasso` (alpha ∈ {0.001, 0.01, 0.1, 0.5, 1, 5, 10, 15, 20, 40})
  - `Ridge` (alpha ∈ {0.001, 0.01, 0.1, 0.5, 1, 5, 10, 15, 20, 40})
  - `DecisionTreeRegressor` (max_depth ∈ {1, 10, 100, 500}, min_samples_split ∈ {5, 10, 100})
- **Подбор:** `GridSearchCV` (cv=5, scoring='neg_mean_absolute_error').
- **Лучшая модель:** **Lasso(alpha=0.1)** с MAE = **5.49** на кросс-валидации.

### Шаг 8. Проверка модели на тестовых данных
- **MAE на тесте: 5.34** ✅ (критерий < 6.8 выполнен).
- **Важность признаков:**
  1. `mean_temperature` — самый важный;
  2. `energy` — второй по важности;
  3. объёмы материалов/проволочек и `gas` — меньший вклад.
- **Проверка на адекватность:** `DummyRegressor(strategy='mean')` даёт MAE = **7.99** → модель обучена корректно.

## 💡 Выводы для бизнеса

1. **Модель `Lasso(alpha=0.1)`** рекомендуется для внедрения в систему имитации технологического процесса:
   - MAE = 5.34 °C — значительно ниже требуемого порога 6.8;
   - модель интерпретируема и устойчива;
   - отсутствует переобучение (тест лучше кросс-валидации).

2. **Ключевые закономерности:**
   - конечная температура сплава в первую очередь определяется **средней промежуточной температурой** и **затраченной энергией**;
   - объёмы легирующих материалов и проволочек влияют слабее;
   - объём продуваемого газа также вносит вклад.

3. **Рекомендации для бизнеса:**
   - **увеличить количество измерений температуры** в процессе плавления для повышения точности `mean_temperature`;
   - **улучшить теплоизоляцию ковша** для снижения теплопотерь и стабилизации температуры;
   - **узнать теплоёмкости материалов и проволочек** — это поможет точнее прогнозировать нагрев;
   - **добиться одинакового времени подачи материалов** для одного и того же сплава, чтобы уменьшить вариативность;
   - **увеличить объём данных** для статистического улучшения модели.
